# Security Policy

## Local-only behavior

`claude-fix` is a local macOS shell script. It does not send telemetry, collect
analytics, contact project servers, or upload Claude profile data.

The script:

- Creates AppleScript launcher apps in `~/Applications`, plus a `Claude Profiles`
  app that handles `claude://` links.
- Points those launchers at your existing `Claude.app`.
- Uses separate local Claude profile directories such as `~/ClaudeWork`.
- Ad-hoc signs the apps it generates, after editing them.
- Compiles `icons/generate_icons.swift` once with your Command Line Tools into
  `~/.claude-fix/icon-tool`, and uses it to draw launcher icons from the icon of
  your installed `Claude.app`. The icon is read, never modified.
- Unless a profile is switched to `own-app off`, makes an unmodified APFS
  clone of `Claude.app` for it in `~/.claude-fix/apps` and sets a Finder custom icon on it.
  If such a profile is pinned, it also builds a small watcher with `swiftc` and runs it
  as a user launch agent. The watcher only looks at apps launched from
  `~/.claude-fix/apps`: when one starts without a profile, it stops it and opens the
  profile through its launcher. It reads no profile data and makes no network requests.
- Removes only apps marked as generated by `claude-fix`. `clean` hands `claude://`
  back to Claude.

The script does not modify, patch, or re-sign `Claude.app`.

`Claude Profiles` passes a `claude://` link only to the Claude profile you pick in
its dialog. Links are never logged or stored. The only thing written to disk is the
name of the profile you picked last (`~/.claude-fix/last-profile`).

## Dependency behavior

The script uses built-in macOS command-line tools only. It does **not** install
Python packages, Homebrew packages, browser helpers, or any other dependencies.

## Reporting a vulnerability

Please open a private security advisory on GitHub, or contact Sergej Fedorovic
through https://strt.it with:

- macOS version
- Claude Desktop version
- command you ran
- relevant terminal output
- why you believe profile data, app bundles, or local system state could be at
  risk

Please do not include personal Claude data, account tokens, cookies, or private
company information in a report.
